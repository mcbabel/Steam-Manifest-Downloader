01 Capability

four blocks

What it does

One file or one App ID goes in. Depot IDs, manifest GIDs and depot keys come back, and the depot contents land in a folder you choose.

Two download engines

A pure Rust pipeline talks to Steam's CDN directly: anonymous login, manifest request codes, chunk download and chunk decryption, all in process, with no .NET involved. It is the default, and the app still labels it experimental. A bundled .NET engine, DepotDownloaderMod, is there when you would rather use that instead.

An interrupted download resumes by verifying the chunks already on disk, so a dropped connection costs you the remainder and not the whole run.

Sources you configure

Point SMD at GitHub repositories, archive.org items or a plain HTTPS folder. Add the Hubcap and Ryuu APIs as well if you hold a key for them.

Sources are queried in the order you set. The check for whether an App ID exists stops at the first source that answers, so the order you choose is the order that decides.

  • githubrepositories you list

  • httpsplain folder
  • hubcapapi, key required
  • ryuuapi, key required
  • probestops at the first answer

Live depot metadata

Platform, architecture and language come from Steam PICS at the moment you look, so the depot list you select from is the one Steam is serving now.

For each depot the app shows the depot ID, the manifest ID, the platform and architecture it targets, and the size.

After the files land

Patching is optional and separate from downloading. You can patch with the gbe_fork emulator, which has a variant picker, 21 settings and per file patch selection. You can detect and remove SteamStub DRM with the bundled Steamless, and install a Steam API check bypass.

You can also add the game to your Steam library as a non-Steam entry, with banner, hero, logo and icon.

02 Sequence

five steps

From file to folder

  1. 01

    Upload or search

    Drag and drop a .lua or .st file onto the window, or search by App ID. Configured sources are queried in the order you set, and the check for an App ID stops at the first source that answers.

  2. 02

    Select depots

    SMD resolves depot IDs, manifest GIDs and depot keys, and reads platform, architecture and language from Steam PICS. You pick the depots you want.

  3. 03

    Download

    Run the pure Rust CDN pipeline or the bundled .NET engine. Contents are written to the folder you pick. An interrupted run resumes by verifying the chunks already on disk.

  4. 04

    Shortcuts and Steam library

    Add the game to your Steam library as a non-Steam entry, with banner, hero, logo and icon attached.

  5. 05

    Emulator

    Optionally patch with gbe_fork using the variant picker, its 21 settings and per file patch selection. Remove SteamStub DRM with the bundled Steamless, or install the Steam API check bypass.

03 Install paper ground

03 Install

three routes

Three ways in, depending on what you run.

Arch based distributions have packages in the AUR. Everywhere else on Linux there is an AppImage, and Windows 10 and 11 have an installer.

Arch, CachyOS, Manjaro

From the AUR

Two packages are available. The first installs the released binary, the second builds locally. They conflict with each other, so only one can be installed.

paru -S steam-manifest-downloader-bin

Released binary.

paru -S steam-manifest-downloader

Builds locally.

Other Linux

AppImage

Take the AppImage from the latest release. It uses WebKitGTK from your system rather than bundling it. On Arch the dependencies are:

sudo pacman -S webkit2gtk-4.1 libayatana-appindicator librsvg

Arch example. The Debian, Fedora and openSUSE equivalents are in the documentation.

Windows 10 and 11

NSIS installer

The installer sits on the same releases page. It installs per user and does not ask for admin rights.

  • installerNSIS, per user
  • adminnot needed
  • runtime.NET 9 Desktop Runtime

The bundled .NET engine needs that runtime, and the app checks for it on first launch. The Rust pipeline does not need it.

05 Questions paper ground

05 Questions

nine answers

Questions

Short answers here, with the longer versions in the documentation.

Which files can I drop in?

A .lua or .st file. The file picker filters on those two extensions, and anything else is turned away with the message Please select a .lua or .st file. You can skip the file entirely and search by App ID instead.

Which systems does it run on?

Windows 10 and 11, and Linux. On Windows there is an NSIS installer that installs per user with no admin rights. On Arch, CachyOS and Manjaro there are two AUR packages, and everywhere else on Linux there is an AppImage that uses system WebKitGTK.

Do I need .NET installed?

Only for the bundled .NET engine, which wants the .NET 9 Desktop Runtime. The app checks for it on first launch. The pure Rust pipeline does chunk download and decryption in process and needs nothing extra.

Where do the depot keys come from?

From the sources you configure: GitHub repositories, archive.org items, a plain HTTPS folder, and the Hubcap and Ryuu APIs if you hold a key. They are queried in the order you set, and the check for whether an App ID exists stops at the first source that answers.

What happens if a download is interrupted?

Start it again and it resumes. The app verifies the chunks already on disk rather than pulling everything a second time.

Which AUR package should I pick?

Use steam-manifest-downloader-bin for the released binary, or steam-manifest-downloader if you would rather build locally. The two conflict, so install one or the other.

What is the emulator step for?

It is optional work after the download. You can patch with gbe_fork, which has a variant picker, 21 settings and per file patch selection. The bundled Steamless can detect and remove SteamStub DRM, and a Steam API check bypass can be installed. None of it is needed to get a depot onto disk.

Does it send anything back?

Telemetry is opt in and off by default. If you switch it on, the payload is sealed on the client before it leaves the machine.

Can it download a beta or private branch?

No. It signs in anonymously, which reaches the public branch only. Anything behind a password needs a tool that can pass those credentials, such as SteamRE's DepotDownloader.
